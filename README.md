Cursory is a JavaScript mouse-trajectory generator that samples from a library of real human paths, then morphs, knots, and jitters them to match a new start and end point while keeping the path human-like. Use it with CommonJS via `const { trajectory } = require("./cursory.js");` and pass `{ x, y }` objects for `from` and `to` to receive an array of `{ x, y }` points (or enable `returnTimings` to get both points and timings) for realistic cursor motion in simulations or automation.
